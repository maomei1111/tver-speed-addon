# Kiwiブラウザー用 TVer再生速度変更アドオン 仕様書・実装指示書

## 1. 目的

Android版KiwiブラウザーでTVerを開いた際、動画の再生速度を手動または自動で変更できるChrome拡張機能を試作する。

## 2. 前提・注意事項

- Kiwi Browserは2025年1月以降メンテナンス終了・アーカイブ化されているため、将来のTVer仕様変更やAndroid更新で動作しなくなる可能性がある。
- 対象は個人利用を想定した試作版とする。
- TVerの広告削除、視聴回数の不正操作、視聴判定の回避、動画ファイル保存機能は実装しない。
- TVer公式の再生速度上限やサービス仕様を意図的に回避する機能として公開・配布しない。
- まずはKiwiに読み込ませて動作確認できることを優先し、デザインや公開準備は後回しにする。

## 3. MVPの対象機能

### 必須機能

1. TVerのページ上で動画要素を検出する。
2. 再生速度を設定する。
3. 速度選択用の小さな固定パネルを表示する。
4. 0.5倍、1倍、1.25倍、1.5倍、2倍、3倍、4倍を選択できる。
5. 選択した速度を端末内に保存する。
6. TVer内で動画が切り替わった場合も、保存済み速度を再適用する。
7. アドオンを一時的にON/OFFできる。

### あればよい機能

- 0.1倍単位の速度入力
- 0.1倍〜5倍の範囲指定
- パネルの表示位置変更
- パネルの透明度変更
- 「動画開始時に自動適用」のON/OFF
- 現在の再生速度表示

## 4. 対象サイト

原則として次のドメインだけで動作させる。

- `tver.jp`
- `*.tver.jp`

TVer以外のサイトではコンテンツスクリプトを実行しない。

## 5. 操作イメージ

1. KiwiブラウザーでTVerを開く。
2. 動画ページを表示する。
3. 画面下部または右下に速度パネルを表示する。
4. `2.0x`などの速度ボタンを押す。
5. 動画の再生速度が変更される。
6. 次の動画や別番組へ移動した場合も、設定速度を自動適用する。

## 7. 技術仕様

### manifest.json

- Chrome拡張機能形式を使用する。
- まずManifest V3で実装する。
- Kiwiで読み込めない場合に備え、必要ならManifest V2互換版を別途作成する。
- `content_scripts`の対象をTVerドメインに限定する。
- `storage`権限を使用して設定速度を保存する。
- 不要な外部通信権限は設定しない。

### content.js

以下の処理を担当する。

- `video`要素の検出
- `video.playbackRate`への速度設定
- 新しいvideo要素が追加された場合の再検出
- SPA形式の画面遷移への対応
- 速度パネルの生成
- 現在速度の表示更新
- 自動適用設定の読み込み

動画要素の監視には、次の組み合わせを使用する。

- 初回実行時の`querySelectorAll('video')`
- `MutationObserver`
- 必要に応じた短時間の再試行処理

無限ループを避けるため、設定済みのvideo要素には再設定間隔を設ける。

### popup.html / popup.js

拡張機能アイコンを押したときの設定画面を担当する。

- 速度選択
- 現在の保存速度表示
- 自動適用ON/OFF
- アドオン有効/無効
- 設定保存

設定は`chrome.storage.local`に保存する。

保存例：

```json
{
  "speed": 2.0,
  "autoApply": true,
  "enabled": true
}
```

## 8. 再生速度変更ロジック

基本処理は次の考え方で実装する。

```javascript
function applySpeed(video, speed) {
  if (!video || !(video instanceof HTMLVideoElement)) return;
  if (video.playbackRate !== speed) {
    video.playbackRate = speed;
  }
}
```

動画が再生開始されたときに戻される可能性があるため、次のイベントを監視する。

- `loadedmetadata`
- `play`
- `playing`
- `ratechange`

`ratechange`イベントで無条件に再設定するとループするため、拡張機能が設定した値と異なる場合のみ再設定する。

## 9. UI仕様

### 速度パネル

- 初期位置：画面右下
- 背景色：黒または濃いグレー
- 文字色：白
- 透明度：80〜90%
- 角丸：8px程度
- ボタン間隔：4〜6px
- 動画操作を邪魔しない小型サイズ

表示例：

```text
[0.5x] [1x] [1.5x] [2x] [3x] [4x]
現在: 2.0x   自動適用: ON
```

モバイル画面で横幅を超えないよう、狭い画面では2段表示または横スクロールにする。

## 10. エラー処理

- video要素が見つからない場合は画面にエラー表示しない。
- 速度設定に失敗した場合は、最大3回まで再試行する。
- TVerの広告・番組切り替えで一時的にvideoが消えても、画面を壊さない。
- `chrome.storage`が利用できない場合は、初期速度1.0倍で動作する。
- 拡張機能APIの非対応エラーをユーザー向けに分かりやすく表示する。

## 11. 実装指示

### フェーズ1：最小動作確認

1. `manifest.json`を作成する。
2. TVerに限定した`content.js`を作成する。
3. ページ内のvideo要素を検出する。
4. 固定ボタンを1つ表示する。
5. ボタン押下で2倍速に変更する。
6. Kiwiに拡張機能を読み込む。
7. TVerの無料動画で再生速度が変わるか確認する。

### フェーズ2：速度選択

1. 速度ボタンを複数追加する。
2. 選択した速度を`chrome.storage.local`に保存する。
3. ページ再読み込み後も速度設定を維持する。
4. 動画切り替え時の再適用を確認する。

### フェーズ3：ポップアップ設定

1. 拡張機能アイコン用のポップアップを作成する。
2. 自動適用ON/OFFを追加する。
3. アドオン有効/無効を追加する。
4. 設定変更が開いているTVerページに反映されるようにする。

### フェーズ4：実機テスト

以下を実機で確認する。

- TVerトップから番組を再生できる
- 再生開始直後に設定速度になる
- 速度ボタンがタップしやすい
- 全画面表示で邪魔にならない
- 縦画面・横画面の両方で使える
- 番組切り替え後も速度が維持される
- 広告終了後に速度が戻らない
- ページ再読み込み後も設定が保持される
- Kiwiを再起動しても設定が保持される

## 12. 確認できない場合の切り分け

### 拡張機能が読み込めない

- Manifest V3非対応の可能性を確認する。
- `manifest_version: 2`の互換版を作成する。
- manifestのJSON構文を確認する。
- 拡張機能フォルダのルートを正しく指定する。

### TVerが再生できない

- Kiwi側のTVer対応状況を確認する。
- PC版サイト表示を試す。
- User-Agent変更は初期実装では行わない。
- DRMやWebView相当の制限であれば、速度変更以前の問題として記録する。

### 速度が変わらない

- video要素が存在するか確認する。
- videoがiframe内に存在しないか確認する。
- content scriptの対象ドメインを確認する。
- `playbackRate`設定後にTVer側が値を戻していないか確認する。
- `MutationObserver`とイベント監視が動作しているか確認する。

## 13. 完了条件

- Kiwiブラウザーに手動インストールできる。
- TVerの動画ページで速度パネルが表示される。
- 1倍・2倍・3倍など複数速度を選択できる。
- 動画再生中に速度が変更される。
- ページを再読み込みしても設定速度が保持される。
- 番組切り替え後も自動適用される。
- TVer以外のサイトでは動作しない。
- 広告削除や視聴判定回避などの機能を含まない。
