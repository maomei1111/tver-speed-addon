# TVer 再生速度変更アドオン（Kiwiブラウザー向け MVP）

Android版KiwiブラウザーでTVer（tver.jp）を開いたときに、動画の再生速度を手動または自動で変更できるChrome拡張機能の試作版です。
詳細仕様は [`docs/kiwi-tver-speed-addon-spec.md`](docs/kiwi-tver-speed-addon-spec.md) を参照してください。

個人利用を想定した試作版です。広告削除・視聴回数の不正操作・視聴判定の回避・動画ダウンロードなどの機能は含みません。

## ファイル構成

```text
tver-speed-addon/
├─ manifest.json      … Manifest V3 定義（TVerドメイン限定）
├─ content.js          … video要素検出・速度適用・パネルUI
├─ content.css         … 速度パネルのスタイル
├─ popup.html/.js/.css … 拡張機能アイコンから開く設定画面
├─ icons/               … 拡張機能アイコン（16/48/128px）
├─ scripts/gen-icons.js … アイコン再生成用スクリプト（Node.js, 任意）
└─ docs/kiwi-tver-speed-addon-spec.md … 仕様書
```

## 機能

- TVer（`tver.jp` / `*.tver.jp`）のページでのみ動作します。他サイトではcontent scriptを実行しません。
- ページ内の`video`要素を検出し、`playbackRate`を設定します。
- 画面右下に速度パネルを表示し、`0.5x / 1x / 1.25x / 1.5x / 2x / 3x / 4x`を選択できます。
- 選択した速度・自動適用ON/OFF・アドオン有効/無効を`chrome.storage.local`に保存します。
- 番組切り替えやSPA遷移で新しい`video`要素が追加されても、`MutationObserver`とポーリングで再検出し、保存済み速度を再適用します。
- 拡張機能アイコンのポップアップから、速度選択・自動適用ON/OFF・アドオン有効/無効を設定できます（開いているTVerページにも反映されます）。
- `chrome.storage`が利用できない環境では、初期速度1.0倍・設定保存なしで動作します。

## Kiwiブラウザーへの読み込み手順

1. このフォルダ（`tver-speed-addon`）をAndroid端末上、またはPCから転送できる場所に置きます。
2. Kiwiブラウザーのアドレスバーに `kiwi://extensions` を入力して開きます。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」をタップし、`manifest.json`のあるフォルダ（このフォルダのルート）を選択します。
5. 拡張機能一覧に「TVer 再生速度変更」が表示されれば読み込み成功です。
6. TVer（`https://tver.jp/`）を開き、動画ページで画面右下に速度パネルが表示されるか確認します。

### 読み込めない場合

- Manifest V3非対応の可能性があります。`manifest_version`を`2`にした互換版manifestを別途作成し、`background`のService Worker記述を取り除くなどの対応が必要です（本MVPでは未同梱）。
- `manifest.json`のJSON構文エラーがないか確認してください。
- 選択したフォルダが`manifest.json`を直接含むルートフォルダになっているか確認してください（サブフォルダを指定すると読み込めません）。

## 実機テスト項目

- [ ] TVerトップから番組を再生できる
- [ ] 再生開始直後に設定速度になる
- [ ] 速度ボタンがタップしやすい
- [ ] 全画面表示で邪魔にならない
- [ ] 縦画面・横画面の両方で使える
- [ ] 番組切り替え後も速度が維持される
- [ ] 広告終了後に速度が戻らない
- [ ] ページ再読み込み後も設定が保持される
- [ ] Kiwiを再起動しても設定が保持される
- [ ] TVer以外のサイトではパネルが表示されない

## 既知の制約

- Kiwi Browserは2025年1月以降メンテナンス終了・アーカイブ化されているため、将来のTVer仕様変更やAndroid更新で動作しなくなる可能性があります。
- TVer側が`playbackRate`を独自に上書きする実装に変更した場合、追随できなくなる可能性があります。
- `video`要素が別オリジンのiframe内にある場合、content scriptから操作できないことがあります（`all_frames: true`にはしていますが、クロスオリジンiframeには適用されません）。
- DRMやTVer固有のWebView相当の再生制限がある場合、速度変更以前に再生自体ができないことがあります。この場合は本アドオンの対象外です。
- 広告削除・視聴回数の不正操作・視聴判定の回避・動画ファイル保存機能は実装していません。今後も実装予定はありません。
- 公開・配布は想定しておらず、個人利用の試作版です。

## 今回作らなかった機能

仕様書のとおり、以下は本MVPに含めていません。

- 広告ブロック
- TVer動画のダウンロード
- TVerアカウント情報・視聴履歴の取得
- 自動スキップ
- 視聴回数や視聴判定の操作
- 複数動画サイトへの対応
